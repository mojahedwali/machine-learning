# ARTI308 – Lab 5

In this lab, we apply basic data preprocessing and machine learning techniques on a food delivery dataset (`talabat_enhanced_orders.csv`). The goal is to prepare the data, create new features, and train a model to predict order status.

A new feature called **Delivery Speed** was created using delivery distance and delivery duration. We also modified the definition of **peak hours** and tested different values of **top_k** to reduce item categories. Finally, feature selection was applied to identify the most important variables.

The notebook trains a machine learning model and evaluates its performance using accuracy.
